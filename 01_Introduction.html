1.2 Histoire du C

1960 - Le langage CPL - Combined Programming Language

1967 - Le langage BCPL - Basic Combined Programming Language [Martin Richard]

1970 - Le langage B [Ken Thompson] : structures de contrôle indépendantes de la machine, sert à écrire des compilateurs et des utilitaires d'UNIX, dont le noyau reste en assembleur


1972 - Le langage C s'inspire fortement des langages B et BCPL des laboratoires Bell [Dennis Ritchie]

1.2 Histoire du C

1973 - UNIX est réécrit en C, à 90%


1978 - K&R C : première version de référence du langage, définie dans le livre The C Programming Language de Kernighan et Ritchie


1983-1989 - ANSI C : American National Standards Institute, résultat d'un effort de standardisation remplace le K&R C, et évolue jusqu'au standard connu comme C ANSI, C89 ou C90


1985 - C++ : évolution du C par Bjarne Stroustrup

Le principal "+" du C++ est la possibilité d'utiliser les concepts de la programmation orientée objet avec l'efficacité du ANSI C

1.2 Histoire du C

1999 - C99 : l'ISO standardise une extension de la norme du langage C, connue sous le nom de C99


2011 - C11 : nouvelle norme du langage C depuis décembre 2011, avec la définition du nouveau standard C11


2018 - C17


2024 - C23

1.3 Avantages du C

Rapide : proche du matériel, pas de machine virtuelle ni de ramasse-miettes

Compact : code et empreinte mémoire réduits

Accès bas niveau : mémoire, registres, périphériques

Portable : le même code source se compile sur (presque) toutes les machines et tous les OS

Omniprésent : noyaux (Linux, Windows), embarqué, interpréteurs (Python, …), bibliothèques système

1.3 Désavantages du C

Clarté non garantie : rien n'empêche d'écrire du code illisible (concours du code obscur)


Portable, mais… : la bibliothèque standard est minimale, tout le reste (interface graphique, réseau, système) dépend de la plateforme


Discipline de programmation : pas de filet de sécurité, gestion manuelle de la mémoire, pas de vérification des bornes

1.5 La compilation

Le C est un langage compilé

Fichier source .c : du texte

Le processeur n'exécute que du langage machine

Compiler = traduire le source en langage machine


La chaîne de compilation : 4 outils

  1. Préprocesseur : #include, #define
  2. Compilateur : C → assembleur
  3. Assembleur : assembleur → code objet
  4. Éditeur de liens : objets + bibliothèques → exécutable

⚠️ Attention : « Compilation » = étape 2 au sens strict, toute la chaîne au sens courant

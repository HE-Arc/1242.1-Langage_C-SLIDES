6.1 Déclaration de fonction

On déclare une fonction avec son prototype

Syntaxe d’un prototype



            TypeDeRetour nomFonction(Type1 [nomParametre1],
                                      Type2 [nomParametre2],
                                      …
                                      TypeN [nomParametreN]
                                     );

Les noms des paramètres sont facultatifs dans le prototype

Le compilateur vérifie l'adéquation entre le prototype et les appels

Le nom de fonction doit être unique. On ne peut pas définir 2 fonctions avec le même nom (pas de surcharge).

[extern/static/] retiré (voir plus tard) Signature: nom de la fonction + liste des types (sans le type de retour)

6.1 Valeur retournée

Instruction : return

⚠ Fonction non void sans return : utiliser sa valeur est un comportement indéfini (UB)

gcc avertit (-Wreturn-type) → erreur avec nos options (-Werror)


L'exécution de toute fonction se termine soit

- à l’exécution d’une instruction return

- à la fin du bloc d’instructions, marqué par }

- par un exit (⚠ le programme complet s’arrête)


Remarque : une fonction peut avoir plusieurs return

6.1 Type de retour

Fonction qui retourne une valeur



                int inc(int nb)
                {
                    return nb + 1;
                }
                int main(void)
                {
                    int x = inc(4);
                    printf("%d\n", x);
                    return 0;
                }

Fonction qui ne retourne rien



                void show(int nb)
                {
                    printf("%d", nb);
                }
                int main(void)
                {
                    show(4);
                    return 0;
                }

6.1 Type de retour

TypeDeRetour nomFonction(...)

Exemples



            void show(...)
            int  inc(...)

TypeDeRetour : entier, réel, pointeur, struct, void

TypeDeRetour doit être compatible avec la valeur retournée par return


⚠ Toujours indiquer le type de retour.

6.3 Passage de paramètres

Deux modes de passage de paramètres


1) Passage par valeur

la fonction reçoit une copie de la valeur : la modifier ne change pas la variable de l’appelant

2) Passage par adresse

la fonction reçoit l’adresse de la variable : elle peut lire et modifier la variable de l’appelant


En C, le passage des paramètres ne se fait que par valeur


Simuler le passage par adresse : voir chapitre Fonction II

la fonction appelante fait une copie des valeurs passées en paramètre dans la pile d'exécution et la fonction appelée utilise ces copies pour ses paramètres. Ces copies disparaîtront lors du retour à la fonction appelante. Donc toute modification de ces copies dans la fonction appelée n'a aucun effet sur les valeurs des variables de la fonction appelante.

6.3 Passage par valeur : exemple



                void increment(int n)
                {
                    n++;
                    printf("n = %d\n", n);
                }

                int main(void)
                {
                    int a = 5;
                    increment(a);
                    printf("a = %d\n", a);
                    return 0;
                }
              


                n = 6
                a = 5

n est une copie de a : modifier n ne change pas a

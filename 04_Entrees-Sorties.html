4.2 Affichage multiple

Un seul printf() peut afficher simultanément plusieurs variables et constantes.

Exemple



            printf("Annee %d, Mois %d, Jour %d\n",1991,5,10);
          


            Annee 1991, Mois 5, Jour 10

La liste d'expressions doit posséder le même nombre de valeurs qu'il y a de spécifications de format.

valeurs supplémentaires : ignorées / valeurs manquantes : comportement indéfini (UB) / si le type des expressions ne correspond pas au format d'affichage spécifié : comportement indéfini (UB), la valeur affichée est imprévisible.

(a) valeurs supplémentaires → ignorées

(b) valeurs manquantes → comportement indéfini (UB) : affichage aléatoire

(c) type des expressions ne correspondant pas au format d'affichage → comportement indéfini (UB) : décodage incorrect

4.2 printf() – types réels

Avec les types réels, le format peut contenir des indications pour la largeur et la précision.

%[drapeaux][L][.P]f

%[drapeaux][L][.P]lf


La spécification de largeur L fixe la largeur minimale de la valeur à afficher.

La spécification de précision P commence toujours par un point et indique que P décimales sont affichées (avec %g : P chiffres significatifs).

Les drapeaux : + affiche toujours le signe, 0 complète à gauche avec des zéros, - aligne à gauche.

Largeur et précision existent aussi pour les entiers et les chaînes : %5d, %.3s.

Les séquences d'échappement commencent par un backslash '\'

4.4 scanf() – format de lecture

La chaîne de commandes de scanf() a les mêmes spécifications de format que printf() sauf pour les types réels

FormattypeReprésentation
%ffloatvaleur signée [-]zzz.fff
%lfdoublevaleur signée [-]zzz.fff

En résumé, avec printf :

%f et %lf pour les variables de type float et double

et avec scanf :

%f pour les variables de type float

%lf pour les variables de type double

Pourquoi ? printf reçoit des valeurs : un float y est converti en double, %f suffit. scanf reçoit des adresses : il doit savoir s'il écrit 4 octets (float) ou 8 (double).

4.4 scanf() – format de lecture

Certains caractères jouent un rôle particulier avec scanf. On les appelle séparateurs ou "caractères blancs". Les plus courants sont      TAB ENTER

Si l'un de ces caractères fait partie de la chaîne de commande, on peut saisir à l'endroit où il se trouve autant de caractères blancs que l'on désire (ou aucun).

Exemple

scanf(" %d %d",&day,&month);

les deux nombres peuvent être séparés par des

%d, %f et %s sautent déjà les blancs qui précèdent la valeur : l'espace du format compte surtout devant %c, %[ et les caractères ordinaires.

4.5 Lire deux caractères (1)

Comment lire deux caractères ?

Méthode 1



                char a, b;
                scanf("%c %c", &a, &b);

x→a ENTER y→b ENTER OK

x→a      y→b ENTER OK

x→a y→b ENTER OK

4.5 Lire deux caractères (2)

Comment lire deux caractères ?

Méthode 2:



                char a, b;
                scanf("%c", &a);
                scanf("%c", &b);

Pas d’espace !



                scanf("%c%c", &a, &b);

x→a y→b ENTER OK

x→a ENTER→b y ENTER PAS OK

x→a     →b y ENTER PAS OK

Précaution :

En cas de plusieurs scanf, mettre un espace devant %c : il saute le ENTER laissé dans le tampon par la saisie précédente

scanf(" %c", &a);

4.5 Limiter la saisie : largeur et %[...]

char ligne[80];

scanf("%79[ ABCDEF]", ligne);

N'accepte que les caractères ABCDEF, ainsi que l’espace ici, dans la variable ligne

Comme vu précédemment, il n'y a pas de signe & ; 79 limite la saisie à la taille de ligne (80, avec le '\0')

scanf("%79[^ABCDEF]", ligne);

Accepte tous les caractères sauf ABCDEF dans la variable ligne

Dès qu’un de ces caractères est trouvé, la saisie s’arrête

4.5 Vider le tampon d'entrée

Après une saisie, le reste de la ligne (au moins le ENTER) reste dans le tampon et sera lu par la saisie suivante.

Pour le jeter, on lit et ignore les caractères jusqu'à la fin de la ligne :



            int c;
            while ((c = getchar()) != '\n' && c != EOF)
            {
            }

c est un int pour pouvoir comparer avec EOF (fin de l'entrée).

⚠ fflush(stdin) : comportement indéfini (UB), fflush ne s'applique qu'aux flux de sortie.

4.5 Valeur de retour de scanf()

status = scanf("%d:%d", &h, &m);

Lit les variables h et m au clavier, séparées du signe :

La variable status (de type int) contient le nombre de paramètres saisis sans erreur, ou EOF si l'entrée se termine avant

Saisie avec validation



            int h, m, status;
            do
            {
                printf("Hour (h:m): ");
                status = scanf("%d:%d", &h, &m);
                if (status == EOF)
                {
                    return 1; // input closed
                }
                int c;
                while ((c = getchar()) != '\n' && c != EOF)
                {
                }
            } while (status != 2);

4.5 Un message qui n'apparaît pas ?

printf écrit d'abord dans un tampon de sortie, vidé à chaque '\n' quand la sortie est un terminal, et à la fin du programme.

Si un message sans '\n' n'apparaît pas avant la saisie (sortie redirigée, certains terminaux), vider le tampon après le printf :



            printf("Hour (h:m): ");
            fflush(stdout);
            scanf("%d:%d", &h, &m);

4.5 Exemple (avec des strings)



            #include <stdio.h>

            int main(void)
            {
              // Messages are "const char *" because they are not supposed to be modified
              const char *enter_your_first_name_msg = "Enter your first name: ";
              const char *enter_your_last_name_msg = "Enter your last name: ";
              // first_name and last_name are arrays of characters because they are supposed to be modified

              printf("%s", enter_your_last_name_msg);
              scanf("%79s", last_name);

              printf("Your name is %s %s\n", first_name, last_name);

            }

4.6 Autres possibilités d’entrée / sortie



            int ch;                     // ‘ch’: caractère (int pour détecter EOF)
            char line[80];              // ‘line’: chaîne de caractères
            int Nmax = sizeof(line);

            puts(line);                 // écrit le texte sur l'écran avec un '\n'*
            fputs(line, stdout);        // Idem sans '\n'*

            gets(line);                 // lit la variable line au clavier* (supprimé en C11)
            gets_s(line, Nmax);         // C11, annexe K optionnelle (absente sous Linux)*
            fgets(line, Nmax, stdin);   // ou lecture d’un flux (garde le '\n')

            putchar(ch);                // affiche le caractère ‘ch’ sur l'écran*

            ch = getchar();             // Lit le caractère ‘ch’ au clavier (tampon)*
            ch = getch();               // Lit le caractère ‘ch’ du clavier (direct, non standard)**

*<stdio.h>

**<conio.h>, Windows uniquement

3.1 Priorité des opérateurs

Dans chaque classe de priorité, les opérateurs ont la même priorité. S'il y a une suite d'opérateurs binaires de même classe, ils sont regroupés de la gauche vers la droite : c'est l'associativité.


Exemple 6/3*2 se lit (6/3)*2 → 4


Les opérateurs unaires préfixés (!x, ++x, --x) et les opérateurs d’affectation (= += -= *= /= %=) sont associatifs de droite à gauche.

Exemple a = b = c se lit a = (b = c)


⚠ Priorité et associativité disent comment l'expression est parenthésée, pas dans quel ordre les opérandes sont évalués : dans f() + g(), g() peut être appelée avant f().

3.1 «Overflow» - dépassement de capacité

Rappel (chapitre 2) : le type d'une variable définit le domaine des valeurs possibles (<limits.h>, <float.h>). Que se passe-t-il lorsqu'on en sort ?

a) Avec les types réels (float, double), la variable prend une valeur spéciale : infinie, affichée inf (HUGE_VAL, INFINITY), ou indéterminée, affichée -nan(ind) (NAN). Macros de <math.h>.

b) Avec les types entiers, les bits en trop sont perdus. Le résultat dépend du cas :

Exception : vers bool, toute valeur non nulle donne 1. gcc ne signale que certains dépassements sur des constantes (-Woverflow), jamais ceux qui ont lieu à l'exécution.

3.1 Règles de conversions implicites

Une conversion implicite est une modification du type prise en charge par le compilateur.


1. Dans une affectation : le résultat de l'expression à droite du signe = est converti dans le type de la variable de gauche, peu importe la perte.


2. Dans une opération : si les opérandes sont de types différents, il y a conversion du type le plus FAIBLE vers le type le plus FORT.

Avant tout calcul, char et short sont promus en int, même entre deux char.

⚠ Signé et non signé : -1 < 1u est faux, car -1 est converti en UINT_MAX (gcc le signale : -Wsign-compare). Le résultat dépend aussi des tailles : sous Windows, unsigned int + long donne un unsigned long.

Conversion explicite (transtypage ou casting)

Une conversion explicite est une modification du type, réalisée par le programmeur grâce à la syntaxe suivante :

(<Type>) <valeur>

Exemples



            (int) 132.45
            (double) 2/3   //   2.0/3

Remarque

Sans transtypage, on peut aussi fixer le type d'une valeur littérale avec le point décimal et des suffixes :

Littéral1717.017.0F17U17L17LL17UL
Typeintdoublefloatunsigned intlonglong longunsigned long

⚠ 17F est invalide (il faut 17.0F). Préférer les majuscules : 17l ressemble à 171.

3.2 L’opérateur d’affectation

En C, l'affectation peut jouer le rôle d'un opérateur en fournissant un résultat pouvant être réutilisé dans le programme.


La partie à gauche de l’opérateur = s’appelle une lvalue.


L'affectation retourne un résultat qui peut aussi être affecté à une variable :

b = (a = 4); ou b = a = 4;

est équivalent à:



            a = 4;
            b = a;

3.2 L’opérateur d’affectation

<Var> = <Var> <Opérateur> <Expression>;


devient


<Var> <Opérateur composé> <Expression>;



Exemple



                compteur = compteur + 2;
                compteur += 2;

} équivalents

OpérateurSignificationExemple

3.3 Les opérateurs d’incrémentation

Les opérateurs ++ et -- peuvent être


(a) préfixés, à gauche de l’opérande

++x vaut la nouvelle valeur de x


(b) postfixés, à droite de l’opérande

x++ vaut l'ancienne valeur de x


Dans les deux cas, x est modifié au plus tard au prochain point de séquence : ne pas lire ni modifier x ailleurs dans la même expression (voir le défi i = i++).

3.4 L'opérateur virgule : « , »

<expression1> , … , <expressionN>


expression1 est évaluée, puis … , puis finalement expressionN. La valeur de expressionN, la plus à droite, est conservée, c’est la valeur de l’opération virgule.


Utilisation courante dans les boucles :



            for(i=1,j=0; j<15; i++, j=j+2){...}

⚠ Les virgules qui séparent les arguments d'une fonction (printf("%d %d", a, b)) ou les variables d'une déclaration (int a, b;) ne sont pas l'opérateur virgule. En particulier, l'ordre d'évaluation des arguments n'est pas fixé.

3.5 Opérateurs de comparaison

Comparaison de variables ou expressions dont le résultat est 0 ou 1 :


{type simple} x {type simple} -> int {0, 1}

Le résultat est un int, pas un bool, même en C23.


Exemples



            bool b = 5 < (3 + 4);
                 b = 'A' > 'Z';

3.5 Exemple de valeurs booléennes

Rappel (chapitre 2) : en C23, bool, true et false sont des mots-clés, sans <stdbool.h>. Un bool ne vaut que 0 ou 1 : toute valeur non nulle convertie en bool donne 1.

Avant C99 : un int (0 = faux, ≠ 0 = vrai). De C99 à C17 : _Bool, ou bool avec <stdbool.h>.




                bool test = true;
                test = (2*3) < 7;
                printf("%d\n", test); // 1
              


                bool test = 3;  // stocke 1
                printf("%d\n", test); // 1
                test = 0.5;     // stocke 1
                printf("%d\n", test); // 1

3.6 Opérateurs logiques

{type simple} x {type simple} -> int {0, 1}

Un opérande vaut faux s'il est nul, vrai sinon. Le résultat est un int, même avec des opérandes bool.


Exemple :

            c = a || b;

3.7 Opérateurs bit-à-bit

Opérateurs qui agissent directement au niveau des bits des mots. La valeur de chaque bit dépend seulement des valeurs des bit(s) à cette position


OpérateurSignificationExemple
&et : « AND »a & b
|ou : « OR »a | b
^ou exclusif : « XOR »a ^ b
~complément à 1~a

Les opérateurs composés sont également autorisés : &=, |= et ^=

⚠ Ne pas confondre & / && et | / || : 2 & 1 vaut 0, 2 && 1 vaut 1.

⚠ x & 1 == 0 se lit x & (1 == 0) : écrire (x & 1) == 0 (gcc le signale : -Wparentheses).

3.8 Extraction d’un octet d’un int



            unsigned int i = 0x12345678;
            unsigned char b;
            int noByte = 1;  // de 0 à 3

            unsigned int mask = 0xFF;
            int n = noByte * 8;

            mask <<= n;
            b =  ( ( i & mask ) >> n );  // 0x56
